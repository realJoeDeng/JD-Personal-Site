# Codex Instructions

This is Joe Deng's personal website project.

## Run commands

- Install dependencies: `npm install`
- Start local dev server: `npm run dev`
- Type-check and build: `npm run build`

## Editing rules

- The visual direction is already approved. Do not redesign the site unless explicitly asked.
- Keep existing scroll / hover / motion effects unless the user asks to simplify them.
- For content edits, prefer editing `src/App.tsx`.
- Images have been extracted from inline base64 into `public/images/generated/`.
- Do not re-embed images as base64. Use files under `public/images/` instead.
